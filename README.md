# Python AI Toolkit

A lightweight Python toolkit for text analysis, dataset statistics, and evaluation of model-generated responses.

## Overview

This project provides reusable Python utilities for working with text datasets and evaluating AI-generated responses.

The toolkit currently supports:

- Text tokenization
- Word-frequency analysis
- Vocabulary extraction
- Dataset statistics
- Exact-match evaluation
- Token-level F1 evaluation
- Automated unit tests
